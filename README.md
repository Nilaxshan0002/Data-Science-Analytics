# Data Science and Analytics

This repository contains data science and analytics projects, practical exercises and research activities focused on exploring datasets, extracting meaningful insights and presenting data-driven findings.

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Microsoft Power BI (if used)

- Data Cleaning
- Exploratory Data Analysis (EDA)

- Data Visualisation

- Develop practical data analysis skills.
- Understand and explore real-world datasets.

- Present insights using visualisations.
- Strengthen Python programming and analytical skills.

## Repository Contents
This repository includes Python scripts, Jupyter Notebooks, datasets, visualisations, analysis reports and related learning resources.
